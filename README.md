# Ramkumar K A — Portfolio

Personal portfolio of Ramkumar K A, SAP Software Engineer and SAP Certified Integration Developer (ABAP, RAP, SAP BTP Integration Suite).

The whole site is one self-contained `index.html` file, with the photo built in.

## Publish on GitHub Pages

1. Create a public repository named `<your-username>.github.io`.
2. Upload `index.html` (and this README) to the repository root and commit.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Visit `https://<your-username>.github.io` after a minute or two.
